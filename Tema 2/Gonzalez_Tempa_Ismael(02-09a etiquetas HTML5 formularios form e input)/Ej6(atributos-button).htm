Atributos de botón

Los botones de tipo submit o image pueden sobrescribir los atributos del formulario al que pertenecen usando los siguientes atributos:

Atributo Descripción
formaction Especifica la URL de destino para el envío del formulario.
formethod Define el método HTTP (GET o POST) para el envío del formulario.
formenctype Especifica cómo se codifican los datos del formulario antes de enviarlos.
formnovalidate Desactiva la validación del formulario para este botón específico.
formtarget Indica dónde se mostrará la respuesta del servidor después de enviar el formulario.
