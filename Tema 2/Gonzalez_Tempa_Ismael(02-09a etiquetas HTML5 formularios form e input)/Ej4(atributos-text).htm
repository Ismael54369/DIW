Atributos de input (tipo texto)

Atributo Descripción (3-4 palabras)
typeDefine el tipo de entrada.
nameNombre para enviar datos.
sizeAncho visible del campo.
maxlengthMáximo de caracteres permitidos.
valueValor inicial del campo.
idIdentificador único del elemento.
disabledDeshabilita el campo completamente.
readonlyCampo de solo lectura.
autocompleteActiva o desactiva autocompletado.
requiredHace el campo obligatorio.
autofocusPone el foco automáticamente.
patternValida con expresión regular.
placeholderMuestra un texto de ayuda.
formAsocia con un formulario.
formnovalidateAnula la validación del form.
