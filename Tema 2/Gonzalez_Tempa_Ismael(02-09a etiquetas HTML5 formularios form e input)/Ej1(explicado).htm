Formularios

¿En qué consiste el funcionamiento de los formularios?

Un formulario en HTML es, en esencia, un conjunto de elementos que permiten a un usuario introducir datos y enviarlos a un servidor para que sean procesados. Piensa en ellos como la versión digital de un formulario de papel que rellenas en una oficina.

El proceso completo se puede resumir en los siguientes pasos:

  1. Recopilación de Datos en el Cliente (Navegador): El usuario ve una serie de campos en la página web, como cuadros de texto (para el nombre), campos de contraseña, botones de opción (para seleccionar una de varias opciones), casillas de verificación (para marcar una o más opciones), menús desplegables, etc. Estos elementos se definen con etiquetas como <input>, <textarea> o <select>, todas contenidas dentro de una etiqueta principal <form>.
  2. Envío de Datos: Una vez que el usuario ha rellenado la información, hace clic en un botón de envío (normalmente un <input type="submit">). Esta acción le indica al navegador que debe recoger todos los datos de los campos del formulario.
  3. Empaquetado y Transmisión: El navegador agrupa los datos en pares de "nombre" y "valor". Cada campo del formulario tiene un atributo name que actúa como identificador, y el "valor" es lo que el usuario ha escrito o seleccionado. Por ejemplo: nombreUsuario=Ismael. Luego, envía este paquete de datos a la URL especificada en el atributo action de la etiqueta <form>.
  4. Método de Envío (GET o POST): La forma en que se envían los datos la define el atributo method:
    • GET: Los datos se adjuntan a la URL (ej: www.servidor.com/procesar?nombreUsuario=Ismael). Es visible, menos seguro y tiene un límite de caracteres. Se usa principalmente para búsquedas.
    • POST: Los datos se envían en el cuerpo de la solicitud HTTP, de forma oculta. Es más seguro y no tiene límite de tamaño, por lo que es ideal para contraseñas, datos personales o grandes cantidades de información.
  5. Procesamiento en el Servidor: Un script en el servidor (escrito en un lenguaje como PHP, Python, Java, etc.) recibe los datos, los valida y realiza una acción con ellos: guardarlos en una base de datos, autenticar a un usuario, enviar un correo electrónico, etc. Finalmente, el servidor suele devolver una nueva página HTML al usuario como respuesta (por ejemplo, una página de confirmación o su perfil de usuario).
