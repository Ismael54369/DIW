## Ejercicios y Exámenes de Diseño de Interfaces Web (DIW)

Este repositorio contiene una colección de ejercicios prácticos y exámenes resueltos de la asignatura **Diseño de Interfaces Web (DIW)**, correspondientes a **todos los temas**. Los archivos demuestran el uso de diversas etiquetas HTML5, formularios, integración con Bootstrap, SVG, animaciones y JavaScript básico para la interacción en el lado del cliente.

---

### Temas Clave Cubiertos

Los archivos de este repositorio demuestran el dominio de los siguientes conceptos:

-   **HTML5 Semántico:** Uso de etiquetas estructurales como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` y `<footer>`.
-   **Formularios HTML5:** Implementación de `<form>`, `<input>` (con varios tipos y atributos), `<textarea>`, `<select>`, `<option>`, `<optgroup>`, `<label>`, `<fieldset>`, `<legend>`, `<datalist>`, `<output>`, `<progress>` y `<meter>`.
-   **Métodos de Envío de Formularios:** Comprensión y aplicación de los métodos GET y POST.
-   **Meta Tags:** Configuración de metadatos del documento (`charset`, `viewport`, `description`, `author`, `keywords`, `robots`, `canonical`).
-   **Estructura y Contenido:** Creación de listas ordenadas y desordenadas, listas de definición, tablas (simples y anidadas), enlaces (internos, externos, descargables, `mailto`), e imágenes (con atributos `alt`, `width`, `height`, `usemap`, `<area>`).
-   **Estilización Básica:** Integración y uso de clases de Bootstrap 5 para un diseño responsivo y moderno.
-   **SVG (Scalable Vector Graphics):**
    -   **Formas Básicas:** `<rect>`, `<circle>`, `<ellipse>`, `<path>`.
    -   **Texto en SVG:** `<text>`, `<tspan>`, `<textPath>`.
    -   **Degradados:** `linearGradient` y `radialGradient`.
    -   **Animaciones SVG:** Uso de `<animate>`, `<animateMotion>`, `<animateTransform>` para crear movimientos, cambios de propiedades y transformaciones.
    -   **Eventos en SVG:** Interacción con elementos SVG mediante eventos como `onclick` y `mouseover`.
-   **JavaScript Básico:** Implementación de funciones simples para interactuar con elementos HTML y SVG, actualizar el DOM y manejar eventos.

### Cómo Visualizar los Ejercicios

Para explorar los ejercicios y exámenes, simplemente abre los archivos con extensión `.htm` o `.html` directamente en tu navegador web. Algunos ejercicios pueden requerir un servidor local para funcionar completamente (especialmente aquellos que simulan envíos de formulario con POST, aunque en los ejemplos se adaptan para funcionar localmente con GET).
